# Documentation Basecamp

Documentation de l'application et des règles de développement. Chaque section est un dossier, chaque page un fichier Markdown avec des liens relatifs, ce qui permet de la publier telle quelle avec un générateur de documentation (MkDocs, Docusaurus, etc.).

| Section | Contenu |
|---|---|
| [architecture/](architecture/README.md) | Vue d'ensemble, principes, structure du monorepo, Clean Architecture |
| [development/](development/README.md) | Mise en route, TDD et tests, Git et hooks, CI, sécurité |
| [services/](services/README.md) | Un document par service : rôle, API, configuration, invariants |
| [deployment/](deployment/README.md) | Pile de production, images par digest, Traefik de la VM |

Cette documentation décrit le projet tel qu'il est conçu. Le suivi d'avancement n'en fait pas partie.
